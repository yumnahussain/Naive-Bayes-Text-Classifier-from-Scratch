# Naive Bayes Text Classifier from Scratch

This repository contains the starter files, directory structure, and guidelines for **Naive Bayes Text Classifier (Sentiment Analysis)**.

---
## Quick Start

### 1. Set Up Python Virtual Environment (Optional)
```bash
python3 -m venv venv
source venv/bin/activate        # On Windows: venv\Scripts\activate
```

### 2. Run Your Classifier
```bash
python app.py
```
This executes `app.py` to train on `data/train.csv` and evaluate on `data/test.csv`.
